# Greenzio

> AI-powered sustainability and ESG platform.

[![Status](https://img.shields.io/badge/status-archived-lightgrey)](#project-status)

Greenzio is an early-stage sustainability and ESG platform designed to help organizations monitor environmental metrics, understand their sustainability performance, and explore AI-assisted reporting and insights.

**[Open the Greenzio MVP →](https://neon-donut-4f9c02.netlify.app/)**

The live demo represents the functional MVP that was developed during the project's active development period.

---

## 📌 Project Overview

Greenzio was an early-stage startup project focused on making sustainability data easier to monitor and understand.

The MVP combined a web-based dashboard with sustainability metrics and an AI-powered assistant.

The project explored how AI and software could simplify corporate sustainability management.

---

## ✨ Features

### Sustainability Dashboard

Provides an overview of key sustainability metrics and environmental performance.

### CO₂ Emissions Tracking

Allows users to monitor carbon-emission-related metrics and understand changes over time.

### Energy Monitoring

Tracks energy-related sustainability data through a centralized interface.

### Water Usage

Provides visibility into water consumption and related sustainability metrics.

### ESG Monitoring

Brings sustainability-related metrics together in one dashboard.

### AI Sustainability Assistant

Uses AI to provide sustainability-related assistance and insights.

### Compliance Overview

Provides an overview of sustainability and ESG-related compliance information.

### Reporting

Presents sustainability information in a format designed to make reporting and analysis easier.
